# Vienna Football Map

An interactive map to discover football matches
and their locations in Vienna, Austria.

## Project Goals

- Collect football match data from selected leagues
- Display upcoming matches and kick-off times
- Visualize football stadiums on an interactive map
- Provide filters for dates, teams and leagues

## Technologies

- Python
- Pandas
- Streamlit
- Git & GitHub
- OpenStreetMap / Leaflet

## Project Status

Currently in development.
